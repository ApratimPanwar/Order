    Before you start

    You will be shown a series of abstract compositions made of simple shapes. For each one you will be asked two questions and given space to explain your answer in your own words.

    There are no right or wrong answers. The compositions were produced in several different ways, and we are not told which is which while rating.

    What this application records

    • Your two ratings for each composition, your optional notes, and when each composition was shown.
    • A random study code such as p-1a2b3c4d5e6f7a8b, generated in your browser. No name, no email, no contact details, no device fingerprint.
    • Your answers stay only in this browser until you choose to download them. The application sends nothing, anywhere, at any point.

    What this application cannot control

    Visiting any web page leaves traces outside the page itself. This page is served by a web host, and web hosts ordinarily record technical information about each request — typically including your IP address, browser and the time of access. We do not receive, request or analyse those logs, and we cannot switch them off. We therefore cannot tell you that your visit is anonymous — only that this application itself records none of it.

    Likewise, if you later send the downloaded file back, it travels through whatever channel you use, and that channel may attach identifying information — an email address, an account name, a filename. The contents of the file do not, but the delivery of it may.

    Stopping, erasing and withdrawing

    • At any point: Stop and withdraw ends the task. Anything you already answered is kept on this device but marked withdrawn and excluded from analysis.
    • Before you send the file back: Erase everything removes it all from this browser. Nothing then exists anywhere, and there is nothing left to withdraw later.
    • After you have sent the file back: it can still be removed, because your study code is inside it. Write the code down from the final screen and quote it when you ask. Without the code we cannot identify which file is yours — there is nothing else in it that points to you.
