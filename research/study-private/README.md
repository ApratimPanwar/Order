# study-private

**Researcher only.** Holds the stimulus key: condition labels and v1 scores.

This directory is deliberately a SIBLING of `study/`, not inside it, so a
static host rooted at `study/` cannot serve it. Do not move it, do not link
to it from the app, and do not copy it into a participant deployment.

Scores here come from the v1 **development candidate**. None of S1-S21 is
approved, so these are not approved measurements.
