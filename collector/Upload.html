What is sent, and what is not

  • Only the file you choose: your ratings, notes, timings and the random study code inside it. This page does not ask for your name or email address, and you do not need to sign in.
  • This page is run by Google Apps Script. Like any web service, Google ordinarily records technical information about each request, such as an IP address. The research team does not receive those logs, and this page cannot turn them off, so we cannot promise that sending the file is anonymous — only that nothing identifying is requested or stored with your responses.
  • The file is kept in a private Google Drive folder, and your responses are copied into a private spreadsheet. Neither is shared publicly, and this page cannot display them to anyone.

Withdrawing responses you have already sent

Erasing the task in your browser removes your answers from that browser only. It does not remove a file you have already sent. To withdraw a file you have sent, enter the study code shown on your final screen (it is also in the file name and inside the file).
